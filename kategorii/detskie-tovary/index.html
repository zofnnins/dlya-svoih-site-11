Одежда и полезные мелочи

Можно искать детскую одежду, обувь, канцелярские принадлежности, текстиль и разрешённые игрушки. Возрастная маркировка не заменяет реальные размеры.

Что проверяем

Материал, комплектацию, размерную таблицу, предупреждения продавца и доступные сведения о товаре. Составы, батарейки и специальные категории согласуются отдельно.

Безопасный выбор

Решение о пригодности товара для ребёнка принимает покупатель по подтверждённым характеристикам. Если данных недостаточно, позицию лучше не выкупать.

Расчёт только по конкретному товару

Расчёт делается отдельно для каждого заказа. Одинаковые на вид товары могут отличаться по весу, упаковке, условиям продавца и способу перевозки.
